# Decisions

*AI-to-learner knowledge transfer study (ECG age). Author: KEYUR SHAILESHKUMAR PATEL (ORCID https://orcid.org/0009-0008-5261-043X).*

Every design choice that shapes the result, who made it, and the reason as it was presented at the time the decision was made.
"Author" means the author picked it from options with consequences shown. "Default" means it was proposed as part of a plan the author approved as a whole, and can still be changed before the preregistration is locked.

## Made by the author

| A1 | 2026-10-26 | Which task should the AI teach? | Age young vs older; sex; exact age | **Age from ECG: under 40 vs 65+** | same | People truly lack this skill, chance is a clean 50%, the analysis stays simple and strict. |
| A2 | 2026-10-26 | Who are the learners? | Language models; small nets; both | **Both, as two experiments** | same | Language models test teaching with words, small nets test teaching with data; together the claim is harder to dismiss. |
| A3 | 2026-10-26 | How are cues taken from the AI? | Feature surrogate + saliency; saliency only; concept discovery | **Feature surrogate + saliency check** | same | Gives named, checkable rules and tests "an explanation is real if a learner can use it". |
| A4 | 2026-10-26 | Primary hypothesis | Cue > feedback right after; cue > nothing; retention | **Cue beats feedback-only on the post-test (H1)** | same | Feedback-only is the fair control: it shows cues add something beyond practice. |
| A5 | 2026-10-26 | Learner models | 3 small families; one small; one 7B | **Qwen2.5-3B, Llama-3.2-3B, Gemma-2-2B** | same | Results cannot be blamed on one model; all fit one GPU. |

| D2 | 2026-11-03 | Known-answer gate and collapse rule for language models? | Gate + collapse, report all; report only; neither | **Gate + collapse, report all** | same | A model that cannot follow a written rule cannot test whether cues teach. |

| D7 | 2026-11-07 | Which ECGs should the exploratory real-data run use? (the author asked to run it before preregistering, replacing D3) | Protected: folds 1-9 only; same splits as the real study | **Protected: folds 1-9 only** | same | You learn about real-data problems without ever touching the data that H1 is tested on (fold 10 and the held-out device stay unseen). | D8 | 2026-11-07 | Llama-3.2-3B and Gemma-2-2B are licence-gated (no HF_TOKEN yet): which language models for the pilot? | Qwen only; add a token for all 3; ungated re-uploads | **Qwen2.5-3B only for the pilot** | same | One official, ungated model is enough to find real-data problems; the prereg keeps all 3 models and the author adds HF_TOKEN before the confirmatory run. |
| D9 | 2026-11-07 | The pilot showed the cue list swings with tiny teacher changes (5 vs 8 cues). How to make it robust? | float64 fix only; fix + cues stable across 5 teachers; fix + one fixed C | **Float64 fix + consensus across 5 teacher seeds (cue kept if chosen by at least 3 of 5)** | same | The cues are the treatment; agreement across seeds describes what the AI reliably uses, not one teacher's random quirks. |
| D10 | 2026-11-08 (confirmed; built into the v0.3 pilot run on 2026-11-07 as the recommended option, while the author's answer was pending) | The scrambled-cue placebo scored 36% on its own (it pointed the wrong way). How to make it neutral? | Re-draw until 45-55% on the cue fold; true directions on non-cue features; keep and report | **Re-draw (fixed seed) until the placebo tally scores 45-55% on the cue fold** | Re-draw until 45-55% | A placebo should carry no information either way; the rule is fixed, seeded and uses only the cue fold. |
| D11 | 2026-11-07 | Stop the v0.2 Qwen pilot and rerun on v0.3? | Stop, rerun at 15/group; stop, rerun at 30/group; let v0.2 finish | **Stop, rerun v0.3 at 30 per group (main + blinded)** | 15/group | The pilot should test the design that will be preregistered; the author kept the larger size. |
| D12 | 2026-11-14 | The pilot showed that Qwen2.5-3B answers almost only one letter, so accuracy sits near 50% in every group while its probabilities still rank the ECGs (P19). Which score should be primary in Experiment A? | Bias-corrected accuracy; ask each item with both letters and average; AUROC of the probabilities; keep raw accuracy as planned | **Bias-corrected accuracy**: each learner's items on a test are split at that learner's own median P(older). Chance stays 50%, the 3-point bar stays, one-letter models still count, raw accuracy is reported beside it | same | Checked on the pilot data, keeps the accuracy scale and the 3-point bar, costs nothing extra. Chosen after seeing the pilot results, and disclosed as such in `prereg/PILOT_DISCLOSURE.md`. |
| D13 | 2026-11-14 | In the pilot and in a follow-up sweep (4 to 128 practice ECGs) the cues never beat plain practice in Experiment B, and scrambled cues did as well (P16). What to do with Experiment B? | Keep it as a secondary experiment; change how nets get the cues; drop it; keep it exactly as planned | **Keep it, as a secondary experiment**: it runs as designed but is no longer a primary test of H1; the preregistration says a null is expected there and why; Experiment A carries the main claim | same | Keeps a second kind of learner and an honest null without tuning the design further on pilot results; costs almost no compute. Made after seeing the pilot and the sweep, and disclosed as such. |
| D14 | 2026-11-14 | In the pilot the AI's cues did not beat feedback-only practice (H1) in Experiment A, but did beat the placebo (H7) in the main run. Which hypothesis is primary? | Keep H1; make H7 primary; H1 and H7 both primary; test scarce practice first | **Keep H1: cues beat feedback-only practice, by at least 3 points** | same | Keeping the question set before the pilot is the strictest choice and is not tuned to the pilot. A null on H1 with H7 supported is still a clear answer. The author knows the pilot suggests H1 may fail. |
| D15 | 2026-11-14 | With the bias-corrected score (D12), which language models are left out? | Flat rule; gate only; keep the old collapse rule | **Flat rule**: a model is left out only if over half its learners give the same probability to over half the post-test cases (they cannot be ranked). One-letter answers (the collapse flag) are reported, not used to remove a model | same | Removes only models whose answers carry no information under the chosen score. In the pilot no Qwen learner was flat. Made after seeing the pilot, and disclosed as such. |
| D16 | 2026-11-14 | In the pilot 24 practice cases alone taught Qwen2.5-3B as much as the cues did, and prompts were 9,000 to 12,000 tokens. How many practice cases in Experiment A? | Keep 24; test 6 cases on Qwen first; switch to 6 without a test | **Keep 24 practice cases** (no change) | same | H1 was kept as set before the pilot (D14); changing the practice size now to give the cues more room would tune the design to the pilot. No further look at pilot data. |
| D17 | 2026-11-20 | The models' 16-bit format adds rounding noise inside the model (up to about 0.06 in probability on the same prompt; P23). Which precision for the confirmatory run? | 16-bit with the float32 answer read-out; full 32-bit; decide after a GPU test | **16-bit (bfloat16) with the answer letters read in float32** (no change from 0.4.0) | same | The noise is small, random and the same for every group, so it cannot favour one; 16-bit is what the pilot tested and keeps the run affordable on a 16 GB GPU. |
| D18 | 2026-11-20 | In the pilot the prior-knowledge probe answered 'higher in older adults' for 17 of 18 measurements, which looks like a letter bias (P20). What to do with the probe? | Ask each question both ways; drop the probe; keep it as it is | **Ask each question both ways**: once with A = higher, once with A = lower; a direction counts as known only if both answers agree | same | Removes the bias the pilot found and keeps a direct measure of prior knowledge at almost no cost. The probe is descriptive only and cannot favour any hypothesis. |

What should the preprint be? | Protocol + pilot paper now; preregistration and GitHub now, paper later; pilot-only paper without preregistration | **Protocol + pilot paper now**: the frozen plan, the synthetic validation and the pilot results, all marked exploratory; a second paper will report the confirmatory results | same | Puts the frozen plan on record before the real test, shows every pilot fact honestly, and leaves the real result for a clean second paper. |
| D20 | 2026-11-27 | The frozen 1.0.0 plan still said "gate and collapse rules" in one place (P25). Allowed because nothing confirmatory has run and OSF was not submitted. |

## Defaults (proposed in approved plans; can be changed before locking)

| # | Choice | Default | Why |
| --- | --- | --- | --- |
| F1 | Age cut-offs | younger = 39 or under; older = 65 or over | A clear gap; both groups large in PTB-XL. |
| F2 | Data splits | PTB-XL folds 1-8 teacher, 9 cues, 10 tests; held-out device = 2nd largest | Official patient-wise folds; the device rule is fixed before seeing data. |
| F3 | Patient overlap | Roles by patient; a patient's other-device ECGs set aside | No patient may appear in two roles (issue P1). |
| F4 | Measurement panel | 18 standard 12SL measurements, fixed in advance | Learners see the same numbers in every group. |
| F5 | Cue rule | Stability selection, 5-8 cues, threshold 0.6; since v0.3 run on 5 teacher seeds, consensus 3 of 5 (D9) | Sparse, stable, teachable. |
| F6 | Items per test | 40 (language models), 200 (nets) | Enough items per learner; context length fits small models. |
| F7 | Gate size and bar | 40 items, 85% | A model that follows rules gets near 100%; chance is 50%. |
| F8 | Collapse rule | learner flagged at 95% same answer; model uninformative if over half its learners collapse. Since v0.4 (D12) the flag is reported but no longer removes a model; a model is removed if over half its learners are *flat* on the post-test (more than half of a learner's items tie at its median, so they cannot be ranked) | Flags only near-total collapse. With the bias-corrected score, favouring one letter no longer hides learning, but answers that cannot be ranked still carry no information. Confirmed by the author (D15). |
| F9 | Nets' no-training group | practice on the same ECGs with shuffled labels | Gives the group variance and matches compute (issue P3). |
| F10 | Answer letters | alternate per learner, exactly balanced per model and group | Removes letter bias from group differences. |
